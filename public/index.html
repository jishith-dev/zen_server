what's built in

  • Native compile

    Straight to machine code through LLVM. No VM, no interpreter step between you and the binary.

  • Struct methods

    Call behavior directly off your data — server.listen(), req.send() — without a class hierarchy to maintain.

  • HTTP, included

    Sockets, routing, and response helpers ship in the standard runtime. No package to install before your first request.

  • Predictable memory

    Structs are explicit about what's a value and what's a handle. Nothing hides an allocation from you.

You're looking at Zen's own output.

This page is served by the program below — compiled with Zen, running as a native binary, answering the request your browser just made.

server.zen listening on :8080 
screen("Zen listening on :8080")

HttpServer server = httpServer.create(8080)

if (server.listen() == 1) {

    while (true) {

        HttpRequest req = server.next()

        if (req.path == "/") {
            req.sendFile("public/index.html", "text/html")
        } else if (req.path == "/styles.css") {
            req.sendFile("public/styles.css", "text/css")
        } else if (req.path == "/script.js") {
            req.sendFile("public/script.js", "application/javascript")
        } else {
            req.status(404)
            req.send("Not found")
        }
    }
}

get started

Clone it, compile it, run it.

git clone https://github.com/your-org/zen.git
cd zen
node bin/zen.js run server.zen

That's the whole setup. No package manager, no build config — one file in, one native process out.
